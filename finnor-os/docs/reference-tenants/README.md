# Phase 4 reference tenant manifests

These are synthetic, non-customer reference manifests used to validate the shared
Tenant Experience Manifest V2 and client-factory path. They contain no credentials,
production identifiers, or claimed business results. Applying either file still
requires the normal factory review and environment-specific authority.

Both tenants use the same workspace-config aggregate, registries, backend role
contract, Work model, and factory stages. Their differences are configuration only.
