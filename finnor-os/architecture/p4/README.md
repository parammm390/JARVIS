# FINNOR Program Search and Symbolic Optimizer P4

P4 is based on the exact locally certified P3 closure `c0965059b92c1b0f73100c4556301044c1b7e9c4` and lives on `codex/p4-program-search`. The P3 closure passed its full certification locally. No remote ref containing that closure was visible in local refs, and a fresh remote fetch was unavailable during the baseline audit, so P4 makes no claim that P3 or P4 is externally published.

`@finnor/program-search` is a pure planning-time search layer over P1 Operational IR, P2 effects/admissibility, and P3 Epistemic State. It normalizes bounded candidate sources, applies nine guarded rewrites, derives causal partial orders, rejects every unresolved or illegal node, invokes typed deterministic SMT and bounded finite-domain CP-SAT only where declared, and extracts a legal winner with a fixed lexicographic objective. Program search identities use the `p4:program:sha256:` domain and never replace BusinessEffect, Work, DomainAction, idempotency, or provider-operation identities.

The SMT boundary is a deterministic finite-domain, typed reference engine for Boolean formulae, equality/inequality, numeric bounds, capability/authority facts, and dependency relations. It is Z3-class in responsibility but does not claim a native Z3 runtime. The CP-SAT boundary is an exact bounded branch-and-bound reference engine for integer assignment, allocation, ordering, and capacity models; it is not forced over ordinary candidates and does not claim an OR-Tools runtime. Both fail closed to `UNKNOWN` when their deterministic bound is exhausted.

The shadow reuses the exact P3 decision-state builder, P2 tenant-scoped static resolution, P1 query program, and existing compatibility lowerer. It has no callback for execution, persistence, Work, Authority, approvals, providers, models, computers, or BusinessEffect creation. The authoritative query result passes through by identity. Structured receipts contain hashes, origins, rewrite proofs, hard reason codes, solver statuses, score vectors, and tie-breaks—never prompts, raw values, provider payloads, credentials, or chain-of-thought—and adapt to the existing CausalReplay contract.
