# Historical release evidence

Everything under this directory is retained for audit and reproducibility only.
Provider names, resource IDs, URLs, credentials, and commands in these artifacts are
not current deployment instructions and must not be executed as a release procedure.

The sole current production authority is
[`infra/deployment/production.contract.json`](../../infra/deployment/production.contract.json),
and the sole current production release path is
[`production-release.yml`](../../.github/workflows/production-release.yml).
