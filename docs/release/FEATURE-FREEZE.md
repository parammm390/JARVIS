# JARVIS Production Feature Freeze

Effective at P0 exit and continuing through P4 certification, this repository is under feature freeze.

Allowed changes are limited to correctness, safety, testing, observability, deployment, documentation,
and launch-pack work required by the JARVIS 4-Day Production Maestro plan.

The following are prohibited until the release candidate is certified:

- New product features or expansion of product scope.
- Provider or framework migrations.
- New UI concepts or visual redesigns.
- Architecture rewrites.

Production deployment remains a separate owner-authorised action after P4 certification.
